2008-06 source layout

The maintained source is workspace/rebuild/2008-06 on RoConstruct work.
The top-level 2008-06 tree is a public source view. See 2008-06/SOURCE_MAP.md
and source-map.json at the repository root for navigation and donor provenance.

Project directories contain recovered source or headers:
  App/src, App/include                 application and DataModel code
  Base/include                         shared base headers
  Network/include                      network headers
  Rendering/include                    rendering headers
  WindowsClient/src, WindowsClient/include   Windows client code
  Unclassified/src, Unclassified/include    project placement unresolved

Migration is incomplete. native-classes/ and native-headers/ contain both
unmoved files and compatibility files for moved implementations or headers.
native-world/ retains recovered world code. A compatibility translation unit
includes the implementation at its new path: compile either path, never both.
Select providers through existing module recipes and patch manifests; do not
infer executable selection from a file's location. In particular, similarly
named definitions can conflict even when object file names differ.

  build/         build, diagnostics and source-view setup tools
  modules/       build recipes
  patches/       native selection and ABI changes
  manifests/     layout and proof inventories
  p6/            client shell and build tooling
  glue/          adapter code
  tests/         regression, matching, ABI, runtime and exploratory checks
  tests/matching, tests/regression, tests/runtime  organized checks; old entry points remain compatible
  experiments/trials/  inactive trial implementations; tests/ retains compatibility paths
  experiments/overlays/  isolated include profiles; legacy paths remain compatible

The optional local Source/ views describe donor inputs from tools/rbxgs/Client
and are not tracked directories. Their availability depends on local setup.
Other local snapshots and experiments remain evidence, not maintained source;
see the catalog for alternative versions and provenance. Do not delete unique
inputs or move experiments without checking build and proof dependencies.

The layout manifests document individual moves and their verification scope.
Moving code or finding an exact body does not establish linked selection, ABI,
runtime safety, a complete class swap or server credit. Full native
CRobloxApp, CMainFrame, CRobloxView and CRobloxDoc integration remains incomplete.
