## Reusable discoveries

1. **Guard-static reference template** (`FactoryProduct::Creator`, 978 unresolved
   same-shape targets in 2009-06/2010-06/2011-06/2012-06). The initializer must be declared
   with **C++ linkage** (not `extern "C"`), so MSVC treats it as potentially throwing and
   wraps the guarded static in `_except_handler4`; the static is bound to a **reference**
   (fast path loads the slot); the argument push precedes the trylevel write; the trylevel is
   *not* restored. Flags `/O2 /Ob2 /Oy /GF /GS- /EHsc /MD`.
   ```cpp
   struct Value { int x; };
   Value& sub_XXXXX(void*);              // C++ linkage, throwing
   extern struct Desc { int pad[8]; } g_00xxxxxx;
   Value& func_YYYYYYYY()
   {
       static Value& value = sub_XXXXX(&g_00xxxxxx);
       return value;
   }
   ```
   Cross-client byte rate: 272/272 (2011-06), 292/292 (2012-06), 237/237 (2010-06),
   177/177 (2009-06).
2. **ABI fact**: MSVC x86 gives internal-linkage (`static`) functions its own register ABI —
   the first stack argument arrives in **EAX** with `this` in ECX, with no stack pushes.
   Confirmed both from the Lua `index2adr` exemplar and by reproducing the call site.
3. **`getCursorName` family**: virtual member returning `std::string` by value from a literal.
   A 99% "code matches, data differs" report quotes the exe literal (`UniversalCursor`), so
   the literal is recoverable from the diagnostic alone.
4. **`new`-expression template**: `T* X::f() { return new T(); }` reproduces the `/GS` cookie
   frame, spill-local, trylevel write, null check and out-of-line constructor call used by
   the Codejock/MFC wrappers.
5. **MFC layout fact (2007-08)**: `CWnd::CreateEx` is vtable **slot 24** (`+0x60`), while the
   pinned `scintilla-mfc-1.20` library header places it at slot 22 (`+0x58`). The shipped
   CWnd has two extra virtuals. `m_hWnd` is at `+0x20`; `CScintillaCtrl` adds two `LRESULT`
   members at `+0x54`/`+0x58`. Every lib-derived Scintilla/Codejock partial that calls a
   fixed vtable slot is off by two slots for the same reason.

## Failed or rejected hypotheses (preserved)

- `extern "C"` initializer for the guard static: no SEH frame, 33% (rejected: C linkage makes
  MSVC treat the call as nothrow).
- C++ EH state variable only (no `/Oy-`): prototype's frame pointer missing, 66-80%.
- `/EHa` instead of `/EHsc` for the creator constructor: extra `sub esp,8` + state save, 72%.
- `mov [esi],0` zeroing attempted via `__declspec(noinline)` default ctor: adds a real call, 87%.
- 2011-06 00635e40: 87% partial. Body stores match exactly; the target needs two extra
  callee-saved pushes (`ebx`, `edi`) and a `mov [ebp-0x10], esp` state save, i.e. one more
  EH-relevant local/member than any tried layout.
- 2007-03 004f40f0: 90% partial. Control flow and the `c * 0x1010101` byte replication match;
  the original allocates the zero-extend in **ECX** where every tried source form allocates
  EAX (11 candidate forms tested, best 90%).
- 2007-08 0045be30: constructor that writes the `CScintillaCtrl` vtable (0x794034, 79 slots
  walked) and calls two MFC80.DLL import thunks as member functions. No eax=this epilogue,
  so it is not a plain constructor. Needs the MFC80 import names (ordinal-only imports) or
  the Scintilla header's ctor body.
- 2010-06 007234d0: `_invalid_parameter_noinfo`-guarded secure-vector copy (`ret 4`, args at
  `[ebp+8]`/`[ebp+0xc]`); needs the STL secure-container template.

## Next experiment, ranked by expected exacts

1. **Finish the guard-static propagation** (966 remaining, zero hypotheses left): submit in
   batches of ≤5 per target with a 10% regression watch. Highest expected exacts per minute.
2. **Creator-constructor family** (373 same-shape instances, 2011-06 alone): the body is
   already byte-correct; only the two callee-saved pushes and the `mov [ebp-0x10], esp` state
   save remain. Try a second member with a non-trivial destructor, or a
   `shared_ptr`-valued member (which needs a second register across `operator new`).
3. **CWnd slot-24 fix** across all lib-derived Scintilla/Codejock partials: the same
   two-extra-virtuals shift explains any fixed-slot mismatch.
4. **Static-function register ABI sweep**: search all clients for call sites whose callee
   reads EAX/ECX (`mov eax,[esp+N]; mov ecx,[esp+M]; call`) and rebuild them with
   internal-linkage helpers.

## Pilot verdict

Success criterion met several times over: ≥2 new exact functions (19), ≥1 exact plus ≥3
reusable discoveries (5), and sibling propagation produced ≥3 verified exacts (11) at $0
cloud cost. Scale: the guard-static propagation is ready to scale immediately; the creator
constructor family should get a 3-target diagnostic pilot before scaling.
