# Native method integration experiments

These recipes reconstruct real native C++ methods; they do not submit raw-mining sources. Diagnostic trials and local exact methods are proposals, not native credit. Only the server accepted-integration ledger and awarded-credit table establish accepted gains. The retention experiment additionally considers exact object bodies absent from verified module ownership and includes vendor/generated native targets. It waits for current jobs to settle before syncing, then minimizes, recompiles, claims and submits one finite integration attempt under unchanged independent gates.

Finder and focused tests are included for reproducibility. Compiler objects, vendor trees, configuration and credentials are excluded.
