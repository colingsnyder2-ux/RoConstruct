# 2016-source retry on 2008-06

Result: **0 new server-verified exacts, 0 improved partial candidates**. Do not scale this method on 2008-06 without new evidence. This pilot does not establish its value for later clients.

Only 2008-06 was queried, compared, or eligible for submission. No paid AI calls. No existing reconstructed source files, matching rules, or vendor files were changed. No submission was necessary, because no local exact candidate was found. Stored exacts and partials therefore remain intact.

## Scope and reproduction

Run `py -3.12 -m benchmarks.source2016_pilot --units 10 --submit`.

Ten vendor translation units were selected deterministically from the highest stored 80–99% candidates whose existing library source filename also occurs in a 2016-source recipe. Eighteen target functions were selected; seventeen produced local scores. Lua preprocessing failed before comparison. Every successfully compiled object was also checked against all 7,219 currently unresolved code functions in 2008-06, with the existing relocation and referenced-data guards.

Units: PacketLogger, System, GImage, GImage_tga, ltable, GImage_png, CoordinateFrame, pngrutil, pngrtran, Matrix3. The target count includes several functions per translation unit.

The compiler was the client's installed VS2008 RTM build 21022. The pilot tried every existing recipe flag/language combination, then `_DLL` preprocessing with the same headers. Each source compiled once per configuration; the existing compiler cache reused objects for target comparisons and fanout.

Sixty-eight journal entries include compile attempts and preprocessing failures: 34 successful candidate evaluations and 34 failed compile/preprocess cases. The successful evaluations contain 62 target comparisons, including repeated configurations; these are not unique-function gains. Sixty comparisons scored lower and two tied their stored score. No candidate was applied, so no stored-score regression occurred.

## Findings

- 2016 G3D declares `G3D_VER 80000`. The highest stored G3D candidates use 6.09 or the older Roblox fork. System/GImage functions fell far below their stored scores; compiler flags did not recover those differences.
- 2016 PNG declares version 1.2.40. Stored near matches come from 1.2.5–1.2.7. Best tested pngrutil score was 94 versus stored 98; the other selected PNG targets also failed to improve.
- 2016 RakNet declares 4.036, dated 2012-02-01. Its `NativeFeatureIncludesOverrides.h` disables PacketLogger, so the ordinary recipe builds no corresponding functions. A temporary wrapper included the guarded overrides, undefines/re-enables only `_RAKNET_SUPPORT_PacketLogger`, then includes the original source. This compiled source expansion contained inline assembly and was rejected by the existing source guard; no bypass was attempted.
- The 2016 Lua fork includes C++ `eh.h` even though files end in `.c`. Existing recipe preprocessing fails in C mode. A C++ include wrapper advanced to missing `script/ScriptContext.h`. Supplying the actual App/include and Base/include roots advanced to an explicit vendor requirement: `_SECURE_SCL` must equal 0 for release builds. Lua remains unfinished, not a demonstrated failure of matching or a success.
- G3D `_DLL` source expansions also contain inline assembly from vendor headers. Self-contained candidate submission rejects these. Those configurations are recorded as blocked, not scored as zero. Ordinary trusted library-recipe configurations did compile and were scored.
- CoordinateFrame and Matrix3 reached their stored best scores on one selected target each, but neither improved them.

## Next experiment

Prioritize referenced-data repair on the already-near-exact older recipes over wholesale 2016 replacement. Keep 2016 as reference material for a specific missing function or independently evidenced shared implementation. A further Lua experiment should start with real vendor release settings (`_SECURE_SCL=0`) and preserve any subsequent missing dependency or incompatible-header result; avoid fabricated ScriptContext/ABI stubs. No broad rollout is justified by this pilot.
